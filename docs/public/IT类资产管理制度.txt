4. 职责 
4.1. 管理体制
 
4.1.1. 集团对 IT 类资产实行统一领导、 归口管理、分级负责、责任到人的管理体制。 
4.1.2. 信息部是集团 IT 类资产统一归口管理部门。 
4.2. IT 类资产的管理模式 
4.2.1. 信息部：作为归口管理部门，主要负责建立集团版的 IT 类资产台账、IT 类资产选型和技术
支持、收发、组织盘点、监督、检查使用部门对资产管理、维护和使用等情况。 
4.2.2. 共用类 IT 资产管理：网络类、安全类 IT 资产由信息部系统安全工程师负责，服务器和机房
内资产由信息部系统管理员负责，其他类 IT 资产由信息部网管归口管理，集团信息总监可以根
据实际情况调整共用类 IT 资产管理的管理员。 
4.2.3. 使用部门：各使用部门分别建立该部门的台账，并负责实物管理，做到账、资产标签、实
物相符，所有 IT 类资产要落实到每个具体负责人。 
4.2.4. 使用人或保管人：IT 类资产使用人负责 IT 类资产的保管和日常管理，防止损坏或遗失。 
4.2.5. IT 类资产的保管责任以使用部门为单位，实行部门长负责制，部门长必须指定一名兼职 IT
类资产管理员并报信息部备案，IT 类资产管理员缺位时，该部门的 IT 类资产管理员默认为该部

门的部门长，当 IT 类资产管理员和部门长同时缺位时，默认为该部门的更上一级主管领导。

4.4.10. 维护、保管本部门 IT 类资产。

5.1.1. IT 类资产分类与编号和编码规则参照《资产管理制度-B 版》相关章节。 
5.1.2. IT 类资产的分类
 
5.1.2.1. IT 类资产：计算机主机、显示器、打印机、复印机、传真机、扫描仪、服务器、路由器、
交换机、机柜、投影仪、UPS 电源、移动硬盘，监控系统、视频会议系统等。 
5.1.2.2. IT 类低值配件：优盘、计算机配件、PPT 翻页笔、8 口交换机等。 
5.1.2.3. IT 类耗材：计算机键盘、鼠标、电源线、硒鼓、墨盒、色带、网线、水晶头，模块等。

5.2. IT 类资产采购和验收 
5.2.1. IT 类资产购买的技术评估由信息部负责。 
5.2.2. IT 类资产购买由集团供应链部负责。 
5.2.3. IT 类资产的添置和管理 
5.2.3.1. IT 类资产添置、更换、升级：由使用部门根据实际工作需要提交 OA《物料请购单》申请，
根据《分权手册》规定的流程审批完成后，信息部 IT 类资产管理员确定具体配置，由集团供应
链部进行采购。 
5.2.3.2. 信息部 IT 类资产管理员负责收集 IT 类资产的最新市场行情信息，向集团供应链部提供购买
参考意见，并负责组织对购买的 IT 类资产进行验收。
 
5.2.4. IT 类资产的采购流程 
5.2.4.1. 请购流程通过 OA《物料请购单》发起，按照《分权手册》规定进行流程审批，其中信息
部配置选型及审批在 2 天内完成，财务按公司付款制度进行付款，采购部门在财务完成付款后
2 天内完成，信息部在收到购买的 IT 类资产后 2 天内完成相关软件的安装。   
5.2.4.2. IT 类资产在购买后， 申请人在3 天内必须审核资产设备使用登记表或资产配件使用登记表，
并在收到 IT 类资产后进行验收。如在信息部通知处理后 3 天内不做处理者，信息部有权收回 IT

类资产，并分发给其它有需要的部门使用。 
5.2.4.3. IT 类资产的登记与验收具体操作细则参照《资产管理制度-B 版》相关章节。 
5.3. IT 类资产日常管理 
5.3.1. 信息部建立 IT 类资产使用情况检查和考核制度，对长期闲置、利用率低下的 IT 类资产，信
息部有权及时进行合理调配，提高资产利用率。 
5.3.2. 对 IT 类资产，信息部每半年组织一次全面盘点，每月按部门按比例组织一次抽查，以确保

账、资产标签、实物相符。盘点完成后，信息部负责将盘点表递交财务部一份。对盘盈盘亏的
IT 类资产， 使用部门应及时查明原因， 分清责任， 并报信息部和资产管理部门按相关规定处理； 
5.3.3. 集团各部门、各分支机构要做好防火、防盗、防暴、防潮、防尘、防锈、防蛀等工作。按
照制度要求对 IT 类资产进行养护、定期检测或修缮，确保完好和使用安全，如因使用、养护和
各种防护措施不当导致设备损坏的，应按照集团规定追究责任人造成的经济损失。
 
5.3.4. 未经资产管理部门授权，严禁私自拆装 IT 类资产，如果发现 IT 类资产跟原配置不相同时，
当事人和使用部门应当承担一切责任，部门长如发现本部门员工私自拆装 IT 类资产，应及时制
止并对当事人提出口头警告，如因工作需要确实须拆装，应当报请信息部由信息部统一办理。 
5.3.5. IT 类资产配置标准 
5.3.5.1. 根据办公用途不同，办公电脑配置分为：高配、中配、普通三类。高配电脑一般用于三维

视频制作、动画制作、电商直播等对CPU、显示卡有极高要求的岗位使用；中配电脑一般用于
二维设计画图、大数据核算等特定岗位使用；普通电脑一般用于常规办公使用。

5.4. IT 类资产借调 
5.4.1. 借调分为部门内借调和跨部门借调。
 
5.4.2. 部门内借调由使用部门 IT 类资产管理员协调和管理，最后将落实情况以书面形式报信息部
备案。 
5.4.3. 跨部门借调由申请借调入部门填写《IT 类资产借调申请表》，交于信息部 IT 类资产管理员

5.4.4. 任何人不得私自将 IT 类资产外借给其它单位使用，若因外借原因泄密而造成损失者，一切

责任由当事人承担。如属本公司的合作公司确因工作需要须借用 IT 类设备的，应由借出部门先
填好 OA《内部联络单》，经本部门部门长、信息部基础运维组负责人审批同意后方能借出。
借出后如有损坏或故障，将由借用部门负责维修费用。信息部 IT 类资产管理员根据审批后的
OA《内部联络单》调整 IT 类设备台账。 
5.4.5. 信息部 IT 类资产管理员负责整个借调过程的协调工作。 
5.5. IT 类资产交接和回收
 
5.5.1. 由于工作部门变动、 调岗时， 应当先进行资产交接并填写OA《资产异动/出售/报废申请单》 、
OA《员工岗位异动申请表》后再进行人员异动。 
5.5.2. 人员离职时继任者未到位的，由离职人员打印《设备资产清单》并将相关 IT 类资产一并交
回信息部 IT 类资产管理员指定位置， 由信息部IT 类资产管理员与离职人员共同进行台帐与实物
清点及签字确认。 因特殊原因不能把 IT 类资产退回到信息部的， 由使用部门IT 类资产管理员发
回信息部 IT 类资产管理员指定位置， 由信息部IT 类资产管理员与离职人员共同进行台帐与实物
清点及签字确认。 因特殊原因不能把 IT 类资产退回到信息部的， 由使用部门IT 类资产管理员发
起 OA《内部联络单》经使用部门部门长、集团信息总监审批通过后，信息部 IT 类资产管理员
按《内部联络单》的要求进行特殊处理。 
5.5.3. 人员离职时继任者已到位的，由离职人员打印《设备资产清单》并同继任者交接清点和签
字确认，并知会信息部 IT 类资产管理员。 
5.5.4. IT 类资产使用人、使用地点需要更换的，由使用部门 IT 类资产管理员与原使用人共同进行
部门台帐与实物清点，核实无误后，最后将落实情况以书面形式报信息部备案。 
5.5.5. IT 类资产闲置或不可用时，使用部门应当交回信息部。

信息部 IT 类资产管理员落实维修。

5.7. IT 类资产报废 
5.7.1. IT 类资产报废标准为符合下列条件之一： 
a、在财务账面上折旧完毕，且信息部判断无使用价值的。 
b、处于长期闲置，且信息部判断无使用场景的。 
c、资产损毁，且走完相关处置流程的。 
d、损坏后，维修价格高于新购价格的 1/2 或累计维修费用已达到新购价格的。 
e、技术落后，质量差，效率低，已属淘汰且不适于继续使用，或技术指标已达不到使用要求的。 
5.7.2. 资产符合报废条件时，信息部门应当指导相关部门进行资产报废。
 
5.7.3. 使用部门申请报废，由使用部门 IT 类资产管理员填写 OA《资产异动/出售/报废申请单》。 
5.7.4. 信息部 IT 类资产管理员对报废资产进行鉴定，并给出处理意见。 
5.7.5. 信息部对报废的资产进行处理并在台账上进行减少。 
5.8. IT 类资产盘点
